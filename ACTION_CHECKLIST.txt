│ STEP 3: Deploy Backend to Railway (5 minutes)                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│ 1. Go to: https://railway.app                                                │
│ 2. Sign in with GitHub                                                       │
│ 3. Click "New Project"                                                       │
│ 4. Select "Deploy from GitHub repo"                                          │
│ 5. Search for: "E-Commerce-Platform-with-Secure-Payment-Gateway-Integration"│
│ 6. Select and authorize                                                      │
│ 7. Add these Environment Variables (VERY IMPORTANT!):                       │
│                                                                               │
│    NODE_ENV=production                                                       │
│    NODE_PORT=5000                                                            │
│    DB_HOST=your-database-host                                                │
│    DB_PORT=3306                                                              │
│    DB_USER=your-db-user                                                      │
│    DB_PASSWORD=your-db-password                                              │
│    DB_NAME=ecommerce_db                                                      │
│    JWT_SECRET=use-a-random-32-character-string                               │
│    ENCRYPTION_KEY=use-a-random-32-char-hex-string                            │
│    STRIPE_SECRET_KEY=sk_live_YOUR_ACTUAL_KEY                                 │
│    PAYPAL_CLIENT_ID=your-client-id                                           │
│    PAYPAL_CLIENT_SECRET=your-client-secret                                   │
│    CORS_ORIGIN=https://your-vercel-url.vercel.app                            │
│                                                                               │
│ 8. Click "Deploy"                                                            │
│ 9. Wait 3-5 minutes                                                          │
│                                                                               │

│ 🔗 SAVE THIS URL!                                                            │
