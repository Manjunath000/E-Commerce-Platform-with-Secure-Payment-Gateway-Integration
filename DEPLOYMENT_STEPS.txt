METHOD 1: RAILWAY (RECOMMENDED - EASIEST)
-----------------------------------------------------------------

STEP 1: Sign Up (2 minutes)
1. Go to: https://railway.app
2. Click "Login"
3. Sign in with GitHub
4. Authorize Railway

STEP 2: Deploy Project (3 minutes)
1. Click "New Project"
2. Select "Deploy from GitHub repo"
3. Choose: E-Commerce-Platform-with-Secure-Payment-Gateway-Integration
4. Railway auto-detects your setup!

STEP 3: Add MySQL (2 minutes)
1. Click "New" in your project
2. Select "Database" → "Add MySQL"
3. Railway auto-connects to backend

STEP 4: Environment Variables (5 minutes)

BACKEND VARIABLES:
------------------
DB_HOST=${{MySQL.MYSQLHOST}}
DB_PORT=${{MySQL.MYSQLPORT}}
DB_USER=${{MySQL.MYSQLUSER}}
DB_PASSWORD=${{MySQL.MYSQLPASSWORD}}
DB_NAME=${{MySQL.MYSQLDATABASE}}
PORT=5000
NODE_ENV=production
JWT_SECRET=your_32_char_secret_here_change_this_for_production_use
STRIPE_SECRET_KEY=sk_test_your_key (get from https://dashboard.stripe.com/apikeys)
STRIPE_PUBLISHABLE_KEY=pk_test_your_key
PAYPAL_MODE=sandbox
PAYPAL_CLIENT_ID=your_id (get from https://developer.paypal.com/)
PAYPAL_CLIENT_SECRET=your_secret
ENCRYPTION_KEY=12345678901234567890123456789012
CLIENT_URL=${{Frontend.RAILWAY_PUBLIC_DOMAIN}}

FRONTEND VARIABLES:
-------------------
VITE_API_URL=https://${{Backend.RAILWAY_PUBLIC_DOMAIN}}/api
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your_key
VITE_PAYPAL_CLIENT_ID=your_paypal_client_id

STEP 5: Deploy! (3 minutes)
1. Railway auto-deploys
2. Wait for build to complete
3. Check logs for any errors

STEP 6: Run Database Migrations
Install Railway CLI:
  Windows: iwr https://railway.app/install.ps1 | iex
  Mac/Linux: curl -fsSL https://railway.app/install.sh | sh

Then run:
  railway login
  railway link
  railway run -- npm run migrate (if you have migration script)

Or manually connect to MySQL and run migrations from database/migrations/

STEP 7: GET YOUR URL! 🎉
1. Click on Frontend service
2. Copy the Railway URL
3. Your site is LIVE at: https://your-project.up.railway.app

SHARE THIS URL ANYWHERE!

METHOD 2: VERCEL (FRONTEND ONLY - FREE)
-----------------------------------------------------------------

STEP 1: Sign Up
1. Go to: https://vercel.com

STEP 2: Import Project
1. Click "Add New" → "Project"
2. Import your GitHub repository

STEP 3: Environment Variables

VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your_key
VITE_PAYPAL_CLIENT_ID=your_paypal_client_id

STEP 4: Deploy
Your frontend will be at: https://your-project.vercel.app

NOTE: You still need to deploy backend separately (use Railway, Heroku, or DigitalOcean)

METHOD 3: RENDER (FREE TIER AVAILABLE)
-----------------------------------------------------------------

STEP 1: Sign Up
1. Go to: https://render.com
2. Sign in with GitHub

STEP 2: Create Web Services
1. New → Web Service
2. Connect repository
3. Create TWO services:
   - Backend (Node.js)
     - Build Command: cd backend && npm install
     - Start Command: cd backend && npm start
   - Frontend (Static Site)
     - Build Command: cd frontend && npm run build
     - Publish Directory: frontend/dist

STEP 3: Add Database
1. New → PostgreSQL (free tier)
   OR use MySQL (paid)

STEP 4: Environment Variables
(Same as Railway - see above)

STEP 5: Deploy
Your URLs:
- Backend: https://your-backend.onrender.com
- Frontend: https://your-frontend.onrender.com

METHOD 4: DIGITALOCEAN (BEST VALUE - $6/MONTH)
-----------------------------------------------------------------

STEP 1: Create Account
1. Go to: https://digitalocean.com
2. Sign up (get $200 credit!)

STEP 2: Create Droplet
1. Click "Create" → "Droplets"
2. Choose: Ubuntu 22.04
3. Select "Docker" from marketplace
4. Plan: Basic $6/month
5. Add SSH key or use password

STEP 3: SSH into Server
ssh root@your_droplet_ip

STEP 4: Clone and Setup
git clone https://github.com/Manjunath000/E-Commerce-Platform-with-Secure-Payment-Gateway-Integration.git
cd E-Commerce-Platform-with-Secure-Payment-Gateway-Integration

# Create .env file
nano .env
(Paste your environment variables - see above)

# Install Docker Compose if not installed
apt install docker-compose

# Start services
docker-compose up -d

STEP 5: Access Your Site
Frontend: http://your_droplet_ip:3000
Backend: http://your_droplet_ip:5000

STEP 6: Add Domain (Optional)
1. Buy domain (GoDaddy, Namecheap)
2. Point A record to your droplet IP
3. Install SSL: 
   apt install certbot python3-certbot-nginx
   certbot --nginx -d yourdomain.com

Your site: https://yourdomain.com
