================================================================
EASIEST WAY TO DEPLOY YOUR FRONTEND (5 MINUTES)
================================================================

Your backend is already running on Railway!
Now let's get your frontend live...

OPTION 1: VERCEL (RECOMMENDED - FREE!)
================================================================

1. Open this link:
   https://vercel.com/new

2. Click "Continue with GitHub"

3. Find and import your repository:
   E-Commerce-Platform-with-Secure-Payment-Gateway-Integration

4. In the configuration screen:
   
   a) Project Name: ecommerce-frontend
   
   b) Framework Preset: Vite
   
   c) Root Directory: Click "Edit" button
      Then select: frontend
   
   d) Build Command: npm run build
   
   e) Output Directory: dist
   
   f) Environment Variables:
      Click "Add Environment Variable"
      
      Name:  VITE_API_URL
      Value: https://e-commerce-platform-with-secure-payment-gateway-production.up.railway.app/api

5. Click "Deploy" button

6. Wait 2-3 minutes while it builds

7. DONE! Copy your URL (looks like):
   https://ecommerce-frontend-abc123.vercel.app

8. Update Railway backend:
   - Go to https://railway.app/dashboard
   - Click your project
   - Click backend service
   - Go to Variables tab
   - Add new variable:
     
     Name:  CLIENT_URL
     Value: https://your-vercel-url.vercel.app
     
   - Click Add

9. YOUR SITE IS LIVE! 🎉
   Share your Vercel URL with anyone!

================================================================

OPTION 2: RAILWAY (KEEP EVERYTHING TOGETHER)
================================================================

1. Go to: https://railway.app/dashboard

2. Click your project (determined-inspiration)

3. Click "+ New" button

4. Select "GitHub Repo"

5. Choose: E-Commerce-Platform-with-Secure-Payment-Gateway-Integration
   (Yes, the same repo!)

6. Click the new service that was created

7. Go to "Settings" tab:
   
   a) Service Name: frontend
   
   b) Scroll to "Root Directory"
      Click "/"
      Type: frontend
      Press Enter
   
   c) Scroll to "Custom Build Command"
      Enter: npm install && npm run build
   
   d) Scroll to "Custom Start Command"
      Enter: npx serve -s dist -l $PORT

8. Go to "Variables" tab:
   
   Click "Raw Editor"
   Paste:
   
   VITE_API_URL=https://e-commerce-platform-with-secure-payment-gateway-production.up.railway.app/api

9. Go to "Deployments" tab

10. Click "Deploy" if it hasn't started automatically

11. Wait 3-4 minutes

12. Click on the URL (looks like):
    https://frontend-production-xyz.up.railway.app

13. YOUR SITE IS LIVE! 🎉

================================================================

WHAT IF SOMETHING DOESN'T WORK?
================================================================

Problem: Blank white page
Solution: Check Vercel/Railway logs for build errors

Problem: "CORS error" in console
Solution: Make sure CLIENT_URL is set in Railway backend

Problem: "Cannot connect to API"
Solution: Check VITE_API_URL is correct (should end with /api)

Problem: "Network Error"
Solution: Backend might be sleeping (Railway free tier)
          Just wait 30 seconds and refresh
